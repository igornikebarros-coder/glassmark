# Glassmark

Native Android app starter with Kotlin, Jetpack Compose and Room.

## Build APK
Use GitHub Actions → Build Glassmark APK → Run workflow. Download the `Glassmark-debug-apk` artifact from the workflow run.

Features currently in the starter: share links to save, local Room storage, search, favorites, manually adding URLs. Google sign-in/cloud synchronization and extended customization are roadmap items and need Firebase/OAuth setup.
